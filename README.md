# Varde – nettside

Nettsiden for kartappen Varde, publisert med GitHub Pages.

- `index.html` – norsk forside
- `en/index.html` – engelsk forside
- `guide/brukerveiledning.html` og `guide/user-guide.html` – brukerveiledningene
- `guide/*.pdf` – PDF-utgavene, laget med `./build-pdf.sh` (krever Google Chrome)
- `assets/` – stil, ikon og skjermbilder

Etter endringer i veiledningene: kjør `./build-pdf.sh` og commit PDF-ene.
